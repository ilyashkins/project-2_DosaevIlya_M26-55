# Primitive DB

Учебный проект консольного приложения базы данных с CRUD-операциями, написанный на Python.

## Установка и запуск
Для установки зависимостей и запуска программы используйте пакетный менеджер `uv`:

```bash
uv sync
uv run database
```

## Управление таблицами
Доступные команды:
* `create_table <имя_таблицы> <столбец1:тип> ...` — создать таблицу.
* `list_tables` — показать список всех таблиц.
* `drop_table <имя_таблицы>` — удалить таблицу.
* `help` — справочная информация.
* `exit` — выход из программы.

## CRUD операции
* `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` — добавить новую запись.
* `select from <имя_таблицы>` — показать все записи таблицы.
* `select from <имя_таблицы> where <столбец> = <значение>` — показать записи по условию.
* `update <имя_таблицы> set <столбец> = <значение> where <столбец> = <значение>` — обновить существующую запись.
* `delete from <имя_таблицы> where <столбец> = <значение>` — удалить запись по условию.
* `info <имя_таблицы>` — вывести информацию о структуре таблицы и количестве записей.

**Примечание:** при вставке данных строковые значения обязательно брать в кавычки.

## Обработка ошибок и подтверждение действий
В проекте реализованы механики с использованием декораторов:
* Обработка ошибок (`@handle_db_errors`): все ключевые функции обернуты в `try...except`, что защищает программу от падения при некорректном вводе или отсутствии файлов.
* Подтверждение опасных действий (`@confirm_action`): перед удалением таблицы или записи программа запрашивает подтверждение `[y/n]`
* Кэширование (`create_cacher`): повторные одинаковые запросы `select` берут данные из кэша, что ускоряет работу, при этом есть очистка кэша при изменении 
данных.
* Замер времени (`@log_time`): функции `insert` и `select` выводят время своего выполнения в консоль.
